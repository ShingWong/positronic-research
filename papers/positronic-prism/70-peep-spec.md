# PEEP — Positronic Engram Exchange Protocol

> **Status:** superseded by RFC — see below.

The canonical PEEP specification now lives in the versioned RFC series under
`rfc/`:

- **[`rfc/PEEP-0001.md`](PEEP-0001.md)** — the Level 1 data contract
  (per-hit record, entity digest, τ-ordered dossier). Normative, RFC-2119,
  grounded in the executable conformance suite.
- **[`rfc/PEEP-0002.md`](PEEP-0002.md)** — the HTTP transport (endpoints,
  auth, federation). Grounded in the `positronic-serve` reference
  implementation and its conformance gate.

This file is retained as a pointer so existing links to `70-peep-spec.md` do
not break. It is **not** a normative document.
